### Tanglegrams can be visualized in auspice using the URL formula:

`https://nextstrain.org/groups/{group}}/{subtype}/{segment}:groups/PekoszLab/{subtype}/{segment}`

Where
- {group} is either `PekoszLab` (private) or `PekoszLab-Public`
- {subtype} is `h1n1`, `h3n2`, or `vic`
- {segment} is either `genome`, `pb2`, `pb1`, `pa`, `ha`, `np`, `na`, `m`, `ns`

#### Example Tanglegram URLs
- Example ha:na tanglegram for Influenza B:
    - https://nextstrain.org/groups/PekoszLab-Public/seasonal-flu/vic/ha:groups/PekoszLab-Public/seasonal-flu/vic/na
- Example ha:na tanglegram for Influenza B filtered to show only C.3, C.3.1, and C.5.1
    - https://nextstrain.org/groups/PekoszLab-Public/seasonal-flu/vic/ha:groups/PekoszLab-Public/seasonal-flu/vic/na?f_clade=C.3,C.3.1,C.5.1

For more  details: [Nextstrain tanglegram documentation](https://docs.nextstrain.org/projects/auspice/en/stable/advanced-functionality/second-trees.html).
